# CLAUDE.md — k8s-dockerhub-detector

## Overview
A shell script that detects where DockerHub images are still used in a Kubernetes cluster, helping teams migrate away before hitting rate limits.

## Tech Stack
- Bash/Shell
- kubectl (Kubernetes CLI)

## Development
```bash
# Make executable
chmod +x inspector.sh

# Run against current cluster context
bash inspector.sh

# Run against a specific namespace
bash inspector.sh -n my-namespace
```

## Architecture
- `inspector.sh` — the single detection script
- `docs/` — documentation

## Key Rules
- Requires kubectl configured with cluster access
- Supports namespace filtering via `-n` flag
- Keep the script POSIX-compatible and dependency-minimal
- Output should clearly identify which workloads reference DockerHub images
